start with fzf and atuin

Date: Mar 25, 2026

Recently started using fzf + atuin together, and honestly… this combo slaps.
They make it ridiculously fast to:

  • search command history (even across sessions)
  • jump to files or directories
  • debug random artifacts without remembering exact paths
install
# fzf (Ubuntu/Debian)
git clone --depth 1 https://github.com/junegunn/fzf.git ~/.fzf
~/.fzf/install
# atuin
curl --proto '=https' --tlsv1.2 -LsSf https://setup.atuin.sh | sh
bash config (~/.bashrc)
# -- fzf ------------------------------------------
# [ -f ~/.fzf.bash ] && source ~/.fzf.bash
export PATH="$HOME/.fzf/bin:$PATH"
# FZF_CTRL_R_COMMAND= FZF_ALT_C_COMMAND= eval "$(fzf --bash)"
FZF_CTRL_R_COMMAND= eval "$(fzf --bash)"

# -- atuin ------------------------------------------
. "$HOME/.atuin/bin/env"
[[ -f ~/.bash-preexec.sh ]] && source ~/.bash-preexec.sh
eval "$(atuin init bash)"
uninstall
# -- fzf ------------------------------------------
~/.fzf/uninstall 2>&1; echo "Exit: $?"
rm -rf ~/.fzf && echo "Removed ~/.fzf"

# -- atuin ------------------------------------------
rm -rf ~/.atuin
rm -f ~/.bash-preexec.sh

and clean up ~/.bashrc

NOTE: in some terminals, <esc> = <alt> and this is quite annoying as it causes a few conflicts with <alt>+c.
